Contributing to Neural Network From Scratch
First off — thanks for being here. This repo only works if people like you add to it.

How to contribute
1. Fork the repo
Click the Fork button at the top right of this page.
2. Clone your fork
bashgit clone https://github.com/YOUR_USERNAME/neural-network-from-scratch.git
3. Create a new branch
bashgit checkout -b your-feature-name
4. Add your code to the right folder
What you're addingWhere it goesSimpler or cleaner basics01_basics/Hidden layers, new activation functions02_intermediate/Backprop, optimizers, dropout03_advanced/Anything finance related04_finance/Real world use caseexamples/
5. Add a comment at the top of your file
Every file should start with:
python# Author: your GitHub username
# Description: what this does in one sentence
# Level: basics / intermediate / advanced / finance
6. Push and open a Pull Request
bashgit add .
git commit -m "Add: your description here"
git push origin your-feature-name
Then open a Pull Request on GitHub and describe what you added.

Rules

Code must run without errors
Add comments explaining what each part does — this is a learning repo
No copying from other repos without credit
Be kind in PR reviews


Not sure what to add?
Check the Roadmap in the README — everything listed there is open for someone to build.
Or open an Issue with your idea first and we'll figure it out together.
