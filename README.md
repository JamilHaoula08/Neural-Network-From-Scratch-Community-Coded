Neural Network From Scratch 


This repo starts with the simplest possible neural network and grows through community contributions. Whether you're a beginner or advanced — there's a level for you to add to.

The Idea
Most neural network repos are either too complex to understand or too simple to be useful. This one grows in layers — literally. Start at level 1, understand it fully, then move up.

Levels
LevelFolderDescriptionStatus0101_basics/20-line neural network from scratch Done0202_intermediate/Add hidden layers, better activation functions Open0303_advanced/Backpropagation, optimizers, regularization Open0404_finance/Stock prediction, trading signals, sentiment analysis Open05examples/Real world use cases Open

Getting Started

bashcd 01_basics

A Note From Me
I started this repo as someone who's still learning. I'm not an expert — I just wanted a place where I could build something real, understand it fully, and watch it grow into something bigger with help from people who know more than me.
The way I'm using this is simple. I start with the basics, I run the code, I break it on purpose just to see what happens, and then I try to fix it. When I don't understand something I paste it into an AI and ask it to explain it to me line by line until it clicks. That's it. No courses, no tutorials I never finish — just real code in front of me that I actually have to deal with.
What I want from the community is the same energy. If you know more than what's already here, add your version. Don't make it perfect — make it readable. Write comments like you're explaining it to someone who just started, because that someone might be me.
The goal isn't to have the most advanced repo on GitHub. It's to have the most honest one — where you can literally watch a neural network go from 20 lines to something that predicts stock prices, one contribution at a time, and understand every step of how it got there.
If you're learning too, you belong here. Push something even if it's not perfect. That's what I will do.
